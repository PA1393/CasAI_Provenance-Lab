# Synthetic intake examples

These deliberately invented short sequences, qualities and variant calls are
software fixtures, not reference genomes, biological samples, experimental
evidence, or validated editing results. The matching FASTA supports a local REF
check only. Its assembly label is not an external registry identity.

- `reads-r1.fastq` and `reads-r2.fastq`: one matched read pair, declared Phred+33.
- `reference.fasta`: an eight-base invented contig.
- `variants.vcf`: a multiallelic site and an explicitly unphased sample genotype.

See [local inspection usage](../../docs/multi-format-intake.md).
